# JanoBuzz v1.0
Professional multilingual blog starter: public site, Bangla/English/Hindi posts, secure cookie/JWT admin login, create/edit/delete, draft/publish, image upload, SEO fields, search/category filter, AdSense-ready slots and sitemap.

## Local
Install Node.js 20+. Copy `.env.example` to `.env`, change the admin password and JWT secret, then run:
npm install
npm start
Open http://localhost:3000 and /admin.html

For public launch, use HTTPS, strong secrets, backups/persistent storage, rate limiting/CSRF protections and proper privacy/cookie pages. Add your approved AdSense code only after approval.
